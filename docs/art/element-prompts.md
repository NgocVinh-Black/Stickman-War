# Prompt ảnh 12 hệ — gom theo hệ, mỗi dòng là một prompt hoàn chỉnh

Mỗi hệ có đủ **16 prompt**: 12 lính + tháp canh + tường thành (cổng đóng / mở) + tượng nhà + bản đồ, tổng 192.
Mỗi khối là một prompt gộp sẵn trên một dòng (phong cách chung + hệ + đối tượng + những thứ cần tránh): bôi đen cả dòng
hoặc bấm nút copy của khối, dán vào công cụ vẽ ảnh và **đính kèm ảnh mẫu của hệ** ghi ở đầu mỗi hệ.
Ảnh tạo xong lưu vào thư mục của hệ `docs/art/<mã hệ>/`, tên file ghi cạnh từng prompt (số thứ tự + loại), thiếu file nào là biết ngay.
Bản giải thích chi tiết ở `docs/art/unit-prompts.md`; sửa file đó thì sửa file này cho khớp.
